# Credits

The Backrooms combines sound and music synthesized in code with a small set of
third-party assets. Everything listed here is public domain (CC0) or openly
licensed, and the attribution is kept so the sources stay traceable.

## Models

Every model is **CC0 / public domain** — no attribution is legally required.

| model | source | author | notes |
| --- | --- | --- | --- |
| First-person arms | [PSX First Person Arms](https://drillimpact.itch.io/psx-first-person-arms-free) | Drill Impact (itch.io) | Trimmed to the three animation clips the game plays. |

The Strider entity is not a third-party asset: it was modeled from scratch for
the game.
